# Price Gap（店頭用 価格比較アプリ）

アメリカ・中国・韓国・日本のラルフローレン公式価格を比べて、お客さんの言語と通貨で見せるアプリ。iPhoneのSafariで動き、ホーム画面に追加すればオフラインでも使える。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面とデザイン |
| `app.js` | 動き（言語、為替、スキャン、表示） |
| `data/items.json` | 商品データ（価格、素材、サイズの一言など）。**価格を直すときはここだけ** |
| `data/barcodes.json` | バーコード番号 → 商品の対応表 |
| `img/` | 商品写真（ファイル名＝商品ID） |
| `sw.js` | オフラインで動かすための仕組み |
| `manifest.webmanifest`, `icons/` | ホーム画面のアイコン |

## 公開のしかた（GitHub Pages・無料）

1. GitHub にログインして、右上の「＋」→「New repository」。名前は `pricegap` など。
2. できたリポジトリで「Add file」→「Upload files」。このフォルダの**中身を全部**（`index.html` などが一番上に来るように）ドラッグして「Commit changes」。
3. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」。
4. 1〜2分で `https://（ユーザー名）.github.io/pricegap/` が開けるようになる。

注意：無料プランの GitHub Pages はリポジトリを公開（Public）にする必要がある。URL を知っている人は誰でも開けるので、URL は店のスタッフ以外に広めないこと。検索エンジンには載らない設定（noindex）にしてある。

## iPhone に入れる

1. Safari で上の URL を開く（**最初の1回はネットが必要**）。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから開く。これでオフラインでも全部動く。
4. 最初に一度「バーコードを読み取る」を押してカメラを許可しておくと、読み取り機能も端末に保存される。

## 毎日の動き

- その日最初に開いたとき、ネットにつながっていれば為替（人民元・円・ウォン）を自動で取り込む。取れなかったら前回の為替を使う。
- 取り込み元：Frankfurter（欧州中央銀行の公表レート、平日に更新）。だめなときは ExchangeRate-API。
- スタッフ設定の「為替を今すぐ更新」で手動でも取り込める。

## バーコード

- タグのバーコードを読むと、`barcodes.json` か、この端末で登録した対応表から商品を探す。
- 未登録のバーコードは「未登録」と出るので、一覧から商品を選ぶと登録される（次からはスキャンだけで出る）。サイズや色ごとにバーコードが違うので、よく出る色・サイズから少しずつ登録していく。
- 登録はその端末にだけ保存される。スタッフ設定の「バーコード登録を書き出す」でコピーして、`data/barcodes.json` の `codes` に貼ってアップロードすれば、全端末で使える。

## 価格を直すとき

`data/items.json` の商品の `p`（各国の価格）と `m`（`ok`＝同じ色、`ref`＝色違い）を直して GitHub にアップロード。アプリは次にネットにつながったとき新しいデータを読み込む。写真やアプリ本体を変えたときは `sw.js` の `VERSION` の日付も変える。
